# 站点小播放器接入规范

## 站点设置

在「工具 → 网抑云 → 精选歌单」预览并发布一张游客可访问的网易云歌单。点击该行「配置小播放器」，打开「在主题页面显示小播放器」并保存。显示「已启用」后，打开博客首页验证。完整操作见[站点管理与排障](站点管理.md#发布精选与开启小播放器)。

首次安装默认关闭。音乐页开启且所选歌单仍能公开访问时，插件会在主题的首页、文章、独立页面、归档、分类、标签和作者页注入资源。音乐页关闭或歌单失效时，小播放器暂停显示，工具设置中会显示原因。

首次展开先读取浏览器里的播放会话。没有会话时，读取所选歌单的前 100 首。小播放器与 Folia 共用公开曲目的队列、位置和播放意图。播放地址由 Halo 同源接口获取，游客和未绑定的用户使用网易云游客身份，已绑定的用户使用本人绑定。跨文档最多恢复 300 首，保留当前曲目。私人曲目使用临时会话，跨文档只保存结束标记。

## 主题作者接入

主题保留普通的 `<head>`，插件通过 Halo 的页头扩展点加载。启用时自动出现右下角的黑胶入口。要指定位置，在模板里预留一个元素，再用主题样式调整其位置。

```html
<ncm-mini-player th:if="${pluginFinder.available('plugin-ncm')}"></ncm-mini-player>
```

一个页面使用一个挂载位置。插件优先挂载到该元素，元素随正文替换时自动重新挂载。也可把元素放在 Swup 容器外，让界面持续显示。主题提供布局，播放器由插件管理。

收起入口和展开面板使用同一个亮暗模式。按以下顺序读取第一个可用的配色信号。

1. 播放器挂载处的 `--ncm-player-color-scheme`。
2. `<html>` 或 `<body>` 上的 `data-color-scheme`。
3. Halo 的 `color-scheme-*`、`.light` 或 `.dark` 类。
4. 旧主题的 `data-theme="light|dark"`。
5. 挂载位置继承的 CSS `color-scheme`。
6. 页面曾使用 `.dark` 类时，移除该类表示浅色。页面尚未给出配色信号时，读取系统偏好。

主题切换时推荐在 `<html>` 上更新 `data-color-scheme="light"`、`"dark"` 或 `"auto"`。自动模式按系统偏好生效。使用 `.dark` 切换的主题可在首次以浅色打开时声明 `.light`，让深色系统也能正确显示浅色。

音乐页的「外观 → 明暗模式」可以选择「跟随站点」。Swup 内嵌时读取博客当前模式，独立打开时使用同源浏览器最近记录的站点模式。未读取到站点模式时跟随系统。音乐页开启即可记录站点模式，包括小播放器关闭时。主题预览的配色只用于当前预览。

已有个人偏好与已发布的站点默认按保存值生效。跟随站点时，配置同步保存「跟随站点」这一选择，博客切色即时更新 Folia 配色和加载外壳。

| CSS 变量 | 用途 |
| --- | --- |
| `--ncm-player-accent` | 主色，影响播放键、进度轨道和边缘色。 |
| `--ncm-player-color-scheme` | 可选覆盖，可用 `light`、`dark` 或 `light dark`。 |
| `--ncm-player-right`、`--ncm-player-bottom` | 浮动入口到右侧和底部的距离。 |
| `--ncm-player-z-index` | 层级，默认 `20`。 |
| `--ncm-player-glass-tint` | 可选的玻璃着色。浅色和深色主题可分别设置半透明颜色。 |

```css
ncm-mini-player {
  --ncm-player-accent: var(--color-primary);
  --ncm-player-bottom: 72px;
}
```

## 位置与展开方向

自动浮动的黑胶可以拖动。轻点打开播放器，拖动时收起面板，松手保存位置。打开卡片后，通过「播放器位置」可用方向键移动或恢复默认位置。用方向键移动时按 Enter 保存，按 Escape 取消。

宽屏和窄屏分别记忆。游客位置保存在当前浏览器，登录后同步当前 Halo 账号自己的位置。超级管理员可在「网抑云 → 工具设置 → 站点小播放器」中拖动预览，保存站点默认位置。位置优先级为主题挂载位、个人位置、站点默认和主题提供的右下角偏移。

贴左时卡片优先向右展开，贴右时优先向左。窄屏会从上方或下方展开，短屏会限制卡片高度。位置按浏览器可见范围和安全区计算，旋转或缩放只调整显示。主题要与自己的悬浮工具栏共用一块区域时，可以把小播放器放进显式挂载位。

## 导航行为

点击小播放器的封面、歌名或歌手可直接进入当前歌曲的 Folia 歌词界面。播放器已确认只能试听时，歌名旁显示「会员」。使用整页导航的主题会恢复播放会话，已接入 Swup 的主题继续使用同一个音频实例。

| 主题的实际导航 | 播放行为 |
| --- | --- |
| 整页导航、刷新、直达独立音乐页 | 目标页面从浏览器恢复当前曲目、队列和位置。启用自动续播时，同一标签页近期仍在播放的公开曲目会在页面加载时尝试续播。浏览器要求播放手势时，小播放器保留曲目和进度，可继续播放。 |
| Swup、PJAX 仅替换主题正文 | 音频和队列继续留在当前文档。挂载元素被替换时自动恢复小播放器。 |
| 已接入的 Swup 4 主题打开 `/music` | Folia 铺满视口，共用小播放器的播放引擎。点「返回博客」或用浏览器后退返回主题时，音频继续播放。 |

### Swup 4 共用 Folia 引擎

在主题初始化现有 Swup 实例后登记。主题先初始化或插件先加载时，都可以完成接入。

```js
const announceSwup = () => document.dispatchEvent(new CustomEvent('ncm:swup-ready', { detail: swup }));
document.addEventListener('ncm:request-swup', announceSwup);
swup.hooks.once('disable', () => document.removeEventListener('ncm:request-swup', announceSwup));
announceSwup();
```

插件处理音乐首页的 Swup 切换时会设置 `visit.meta.ncmMusic = true` 并保留主题容器。有自定义页面入口校验或清理钩子的主题，应在这个标记下跳过自身的容器检查和销毁，继续执行 Swup 默认切换。验收时确认 `/music` 与返回主题前后使用同一个 Folia 播放实例。

首次播放、打开 `/music` 或接续有效的播放会话时加载 Folia。直接访问、刷新、在新标签页打开 `/music` 或直达音乐详情时，浏览器会打开独立音乐页，公开队列按双向续播规则恢复。独立音乐页整页返回已接入的主题时，自动续播使用主题现有的常驻 Folia 引擎。

为每套主题验证首页进入文章或归档、回到首页、浏览器前进后退，以及亮暗切换。判断连续播放以实际文档和音频实例是否保留为准。启用 Swup 或 PJAX 的主题也可能对部分链接采用整页导航。

Chromium 在展开面板上启用边缘折射。其它内核用 CSS 模糊和高光，系统开启降低透明度时使用实色面板。

[Halo 插件与主题集成](https://docs.halo.run/developer-guide/plugin/theme-integration) · [Halo 主题配色约定](https://docs.halo.run/developer-guide/theme/plugin-integration#适配插件组件配色)

## 双向续播验收

以下记录对应当时的主题和测试版本。较新的 QA 包复验与候选包验收要求见[构建与发布](构建与发布.md)。

2026 年 11 月 24 日在本地 8090 实例用真实网易云曲目验证。Earth 预览与独立 Folia 整页切换后保留了同一首歌和 300 首队列。Sky Blog 1 `3.0.2-qa.27` 在 16.19 秒恢复播放，进入音乐页、返回博客、后退和前进时复用同一个音频对象，期间无暂停或重新加载事件。在 390 px 视口从 Folia 暂停后返回博客，小播放器同步了暂停状态和位置。

## 网络与限流验收

此前在同一隔离站保存较小的测试额度，再按顺序发送真实请求。下表中的数字是 HTTP 状态码。当前安全修复之后的限流、代理验收见[构建与发布](构建与发布.md#发布前验收)。

| 链路 | 测试额度 | 实测 |
| --- | --- | --- |
| 通用个人接口 | 1 次每账号 | 403、429。验收账号未绑定网易云，首个请求被账号校验拦下。 |
| 同 IP 的通用公开接口 | 2 次每 IP | 在个人请求之后仍得到 200、200、429，确认两种额度分别计数。 |
| 音乐页搜索和联想 | 各 1 次 | 两条链路各自返回 200、429。 |
| 游客播放取址 | 公开额度的 2 倍 | 4 次 200，第 5 次 429。 |
| 登录用户播放取址 | 个人额度的 2 倍 | 2 次 200，第 3 次 429。 |
| 公开请求额度为 0 | 不限流 | 连续 3 次 200。 |

隔离代理实际转发到网易云，播放取址返回 200。恢复直连后再次取址返回 200。固定窗口重置和不同来源计数隔离有自动化测试。
