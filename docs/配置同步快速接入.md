# 配置同步快速接入

适用于运行在同一 Halo 站点的音乐页或主题。只读取 Folia 的站点默认时，使用 `GET /apis/api.ncm.halo.run/v1alpha1/config-defaults/folia` 即可。需要独立保存配置时，按下面三步接入。歌词、封面、媒体、分析数据及播放会话由浏览器管理。

## 1. 登记客户端

在音乐插件源码中添加 `src/main/resources/config-clients/demo-player.json`，随插件构建并安装。适配端使用同名 `clientId`。标识限 1–63 个小写字母、数字和连字符，首尾为字母或数字。

```json
{
  "schemaVersion": 1,
  "groups": {
    "playback": {
      "volume": "range:0:1",
      "loopMode": "enum:off|all|one"
    },
    "interaction": {
      "shortcut": "text?"
    }
  },
  "personalOnly": ["interaction.shortcut"]
}
```

`groups` 声明允许写入的字段。`?` 允许空值。`personalOnly` 中的字段只能保存到个人配置。登记由音乐插件打包，主题开发者可把清单交给插件维护者集成。[Folia 清单示例](../frontstage/folia/adapter/foliaConfigPolicy.json)

## 2. 读取并应用

示例同时读取站点默认和个人配置。游客只应用公开默认，登录后按字段应用**内置 → 站点 → 个人**。用 `profileKey` 隔离本机草稿，换号时取消待提交操作并重新读取。以下代码可复制到浏览器 ES 模块。

```js
const base = '/apis/api.ncm.halo.run/v1alpha1';
const clientId = 'demo-player';
const sitePath = `config-defaults/${clientId}`;
const myPath = `my-configs/${clientId}`;

async function request(path, body, method = body ? 'PUT' : 'GET') {
  const response = await fetch(`${base}/${path}`, {
    method,
    credentials: 'same-origin',
    redirect: 'manual',
    cache: 'no-store',
    headers: body
      ? { Accept: 'application/json', 'Content-Type': 'application/json', 'X-NCM-Request': '1' }
      : { Accept: 'application/json' },
    body: body ? JSON.stringify(body) : undefined,
  });
  if (!response.ok) {
    const status = response.type === 'opaqueredirect' ? 401 : response.status;
    throw Object.assign(new Error(`配置请求失败 (${status})`), { status });
  }
  return response.json();
}

export async function loadConfig() {
  const [site, mine] = await Promise.all([
    request(sitePath),
    request(myPath).catch(error => {
      if (error.status === 401 || error.status === 403) return null;
      throw error;
    }),
  ]);
  const config = {
    playback: { volume: 1, loopMode: 'all', ...site.config?.playback, ...mine?.snapshot.config?.playback },
    interaction: { shortcut: null, ...mine?.snapshot.config?.interaction },
  };
  return { site, mine, config };
}
```

## 3. 保存当前配置

修改先在本机生效。个人同步开启后，合并短时间内的修改再发请求。每次 `PUT` 替换目标的完整配置。首次保存也先读取，即使 `config` 为空，仍使用返回的 `schemaVersion` 和 `revision`。保存成功后用响应替换旧快照。

```js
export async function saveMine(state, config) {
  if (!state.mine) throw new Error('请先登录 Halo');
  const { schemaVersion, revision } = state.mine.snapshot;
  state.mine.snapshot = await request(myPath, { schemaVersion, revision, config });
}

// 仅绑定到超管主动点击的「保存为站点默认」
export async function publishDefaults(state, config) {
  if (state.mine?.canPublishSite !== true) throw new Error('需要超级管理员权限');
  const { schemaVersion, revision } = state.site;
  const { volume, loopMode } = config.playback;
  state.site = await request(sitePath, {
    schemaVersion,
    revision,
    config: { playback: { volume, loopMode } },
  });
}

export async function restoreDefaults(state) {
  if (state.mine?.canPublishSite !== true || !state.site.hasPrevious) {
    throw new Error('当前没有可恢复的站点默认');
  }
  const { schemaVersion, revision } = state.site;
  state.site = await request(`${sitePath}/restore`, { schemaVersion, revision }, 'POST');
}
```

- 发布按钮默认隐藏，收到 `canPublishSite: true` 后显示。诊断入口使用 `canViewDiagnostics`。服务端按 Halo 当前登录身份校验。
- 使用当前个人配置版本提交空的 `config: {}` 可清除云端覆盖值，已开启同步时回到站点默认。`GET /config-defaults/{clientId}` 的 `hasPrevious` 表示可恢复上一版。仅超级管理员可带站点的 `schemaVersion` 和 `revision` 提交 `POST /config-defaults/{clientId}/restore`。
- `409` 表示版本冲突。保留草稿并读取最新版本，由用户决定采用云端配置或用新版本保存本机配置。网络失败时继续使用本机值。
- `400` 检查字段、类型和版本，`404` 检查客户端清单是否已随插件安装，`413` 检查请求是否超过 64 KiB，`429` 时等待配额恢复。

验收时用游客和普通用户各打开一次。游客能读取公开默认，普通用户能保存自己的配置，发布按钮仅对超管显示。
