# 开发与接口

## 主题模板与文章卡片

音乐页 `/music` 使用插件打包的 Folia Web 页面。主题可链接音乐页，也可通过 `ncmFinder` 读取公开音乐数据。模板中先确认插件可用。网易云 ID 按字符串传递。

```html
<th:block th:if="${pluginFinder.available('plugin-ncm')}">
  <th:block th:with="song=${ncmFinder.song('186016')}">
    <a th:if="${song != null}" th:href="${'/music/song/' + song.id}" th:text="${song.name}"></a>
  </th:block>
</th:block>
```

| 数据 | 方法 |
| --- | --- |
| 歌曲与歌词 | `song(id)`、`songs(ids)`、`lyric(id)`、`playUrl(id, level)` |
| 歌单、专辑、歌手 | `playlist(id, limit)`、`playlistTracks(id, offset, limit)`、`album(id)`、`artist(id, limit)` |
| 搜索 | `search(keyword, type, page, size)`、`suggest(keyword)`、`hotKeywords(limit)` |
| 站长已公开的数据 | `siteProfile()`、`sitePlaylists(limit)`、`siteWeekRank(limit)`、`siteAllRank(limit)` |
| 图片 | `thumbnail(url, size)` |

公开主题查询使用游客身份，结果默认缓存 600 秒。列表的默认值和上限按各方法确定。主题可以对空值或空列表显示空态。`playable` 和 `availability` 用于展示预估状态，播放时应重新取址。旧模板的 `siteRecentSongs()` 和 `siteDailyRecommend()` 返回空列表，听歌历史与个性化推荐由本人曲库提供。[Finder 契约](../src/main/java/cn/sky/ncm/finder/NcmFinder.java) · [返回模型](../src/main/java/cn/sky/ncm/finder/vo)

在 Halo 编辑器的「插入」菜单可添加歌曲、专辑和歌单卡片。音乐页关闭时，卡片可链接至对应的网易云页面。博客小播放器的外观变量和导航接入见[站点小播放器接入](站点小播放器接入.md)。

## HTTP 接口

| 路径 | 用途 |
| --- | --- |
| `/apis/api.ncm.halo.run/v1alpha1/public/{name}` | 公开只读能力，调用身份固定为网易云游客。 |
| `/apis/api.ncm.halo.run/v1alpha1/personal/{name}` | 当前 Halo 用户绑定的网易云账号，包含个人只读和授权写入。 |
| `/apis/api.ncm.halo.run/v1alpha1/meta/apis` | 接口名、能力、实现状态及 `open`、`debuggable`。 |
| `/apis/uc.api.ncm.halo.run/v1alpha1/binding` | 本人的网易云绑定状态、扫码、手机绑定与解绑。 |
| `/apis/uc.api.ncm.halo.run/v1alpha1/me/-/` | 本人的个人曲库、收藏、推荐、历史和云盘。歌单曲目接口使用同一分组下的 `playlists/{id}/tracks`。 |
| `/apis/console.api.ncm.halo.run/v1alpha1/` | 站长绑定、游客设备、精选发布、调试和产品设置。 |
| `/apis/api.ncm-ai.halo.run/v1alpha1/` | 登录用户的 `GET capabilities/-`、`POST themes` 和 `POST segmentations`。 |
| `/music/play/{id}`、`/music/lyric/{id}`、`/music/chorus/{id}`、`/music/search/suggest` | 音源、歌词、副歌区间和搜索联想。 |
| `/music/card/{type}/{id}` | 读取文章音乐卡片。 |

### 通用接口权限

| 能力 | 调用方式 |
| --- | --- |
| `public` | `GET /public/{name}` 可公开读取。带相应 Halo 权限时也可用 `POST` 提交参数，调用仍使用游客身份。 |
| `personal` | `GET /personal/{name}` 使用当前登录用户的本人绑定。 |
| `write` | `POST /personal/{name}` 需要 Halo 写入权限、本人绑定及同站写入校验。 |
| `auth`、`admin` | 由专用登录、管理或插件内部流程调用。 |

路径前缀为 `/apis/api.ncm.halo.run/v1alpha1`。通过浏览器同源调用个人接口时使用 Halo 的登录会话。写入提交 `X-NCM-Request: 1`，同时满足 Halo 授权。通用上传使用 `multipart/form-data`，字段因操作而异，见[上传接口](../src/main/java/cn/sky/ncm/api/more/UploadApis.java)。

`open` 表示能力已实现且有通用调用路径，具体调用条件由 Halo 角色决定。`debuggable` 标识可用游客身份在调试台调用的接口。接口能力以[清单](../src/main/resources/ncm-apis.json)和[角色模板](../src/main/resources/extensions/role-templates.yaml)为准。

### 音乐页数据与取址

公开详情加 `format=json` 可读数据。歌单曲目支持 `limit` 和 `offset`。`/music?format=json` 返回探索用的站点精选等内容，公开详情同时提供搜索引擎使用的元数据。搜索和个人曲库页面设置 `noindex`。[音乐页路由](../src/main/java/cn/sky/ncm/page/MusicPageRouter.java)

`GET /music/play/{id}?format=json&level=standard` 返回 `status`、`url`、`identity`、`level`、`br`，试听时还有 `trial.start` 和 `trial.end`，单位为毫秒。`identity` 为 `guest` 或 `user`。省略 `format=json` 时成功返回 302。音频加载失败后，可用 `fresh=1` 重新取址。音源地址由当前请求者的播放权限决定，并可能过期。

| 结果 | 处理方式 |
| --- | --- |
| `200` 且含 `url` | 播放该音源。按 `trial` 标记试听并处理范围。 |
| `404` | 当前曲目没有可用音源或 ID 不存在。 |
| `503` | 上游或插件服务暂不可用，允许稍后重试。 |
| `429` | 达到当前配额，稍后再请求。 |

歌词接口加 `view=timed` 可取得 Folia 使用的歌词格式。完整形状见[播放器路由](../src/main/java/cn/sky/ncm/page/PlayerRouter.java)。

### 配置同步 API

| 方法与路径 | 权限 |
| --- | --- |
| `GET /config-defaults/{clientId}` | 公开读取已发布的站点默认。 |
| `GET /my-configs/{clientId}`、`PUT /my-configs/{clientId}` | 当前 Halo 账户读写自己的配置。 |
| `PUT /config-defaults/{clientId}`、`POST /config-defaults/{clientId}/restore` | 超级管理员发布或恢复站点默认。 |

路径前缀为 `/apis/api.ncm.halo.run/v1alpha1`。Folia 客户端标识为 `folia`，小播放器为 `mini-player`。字段白名单、版本冲突处理、完整示例和新客户端登记见[配置同步快速接入](配置同步快速接入.md)。

## API Client 与移植范围

运行中的 Halo 可通过 Swagger UI 查阅 **Extension API for plugin-ncm**。Console 和个人中心使用 [生成的 TypeScript API Client](../ui/src/api/generated/)。更新契约后的生成方法见[构建与发布](构建与发布.md#日常开发)。

接口描述表参考 NeteaseCloudMusicApiEnhanced。当前目录共 459 项，其中 372 项由描述表执行，84 项为手写实现。`register_checktoken_v2`、`register_neapikey`、`song_url_match` 未移植。部分 v2 验证令牌调用沿用 v3，听歌打卡使用 gzip。通用调用和页面功能的支持范围由本仓库接口、角色和对应测试约定。
