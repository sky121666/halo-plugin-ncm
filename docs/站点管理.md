# 站点管理与排障

## 首次安装

安装后先以游客身份打开 `/music`，搜索并试听一首歌。首次安装默认开启音乐页、关闭站点小播放器。游客会话由插件自动初始化，此流程无需配置站长网易云账号。安装位置和最低版本见 [README](../README.md#安装与快速开始)。

## 管理入口

| Halo 入口 | 作用 |
| --- | --- |
| 工具 → 网抑云 → 音乐首页 | 「页面与分享」设置音乐页名称、站点图标或自定义图标及分享信息。「搜索」「探索」「播放」分别管理联想、公开内容和播放行为。 |
| 工具 → 网抑云 → 精选歌单 | 添加公开歌单，试听抽查，管理标题、简介、草稿、发布和顺序。 |
| 工具 → 网抑云 → 账号与游客 | 管理站长网易云绑定和查看游客会话。 |
| 工具 → 网抑云 → 工具设置 | 设置站点小播放器、默认悬浮位置、音乐 AI 和允许使用的角色。 |
| 插件 → 网抑云 → 管理入口 | 按当前 Halo 权限展示可用入口。 |
| 插件 → 网抑云 → 维护 | 检查游客、设备、公钥、凭据和代理状态。 |
| 插件 → 网抑云 → 接口调试 | 以游客身份调试公开只读接口，响应会隐藏凭据。 |
| 插件 → 网抑云 → 网络与限流 | 配置代理、来源 IP、配额、缓存和上传上限。 |

### 管理权限

- **网抑云精选歌单**负责精选歌单。原有「网抑云管理」角色保留精选歌单权限。
- **网抑云账号与游客**负责站长绑定和游客状态。可由 Halo 超级管理员独立授权。
- **网抑云接口调试**负责只读调试和音乐页开发者入口。具备该角色的用户及超级管理员可使用诊断入口。
- **Halo 插件管理权限**用于维护、网络、音乐首页及工具设置。**站点默认偏好**由 Halo 超级管理员发布或恢复。角色授权和个人偏好是两套权限。 [角色模板](../src/main/resources/extensions/role-templates.yaml) · [Halo 用户与权限](https://docs.halo.run/guide/use/users)

## 发布精选与开启小播放器

1. 打开「精选歌单 → 添加歌单」，粘贴网易云歌单链接或 ID。预览时确认游客能访问，按需试听抽查。
2. 设置展示标题、简介，保存草稿或直接发布。已发布且可公开访问的歌单按后台顺序展示在「探索」。
3. 在已发布歌单行选择「配置小播放器」。打开「在主题页面显示小播放器」，选择歌单，保存。
4. 到博客首页打开黑胶按钮。点击封面、歌名或歌手可进入当前歌曲的歌词页。首次展开优先恢复浏览器会话，否则读取所选歌单的前 100 首。

音乐页关闭或所选歌单不可访问时，插件会暂停显示小播放器。原因可在「工具设置 → 站点小播放器」查看。主题挂载、位置、亮暗切换和跨页行为见[站点小播放器接入](站点小播放器接入.md)。

## 账号与游客身份

- **个人绑定**从音乐首页、「音质」面板或「个人中心 → 网抑云」进入。扫码后在网易云音乐 App 确认。音乐页按当前 Halo 登录账号读取绑定，换号后使用新账号的绑定。
- **站长绑定**在「账号与游客」管理。完成绑定的同一个 Halo 账号可在前台使用该站长绑定。有个人绑定时优先使用个人绑定。公开页面、主题公开查询和游客取址固定使用游客权限。
- **解绑**在原绑定的管理入口执行。个人账号解绑后，如当前 Halo 账号还有可用的站长绑定，前台继续使用该账号自己的站长绑定。其他用户解绑后恢复游客播放权限。
- **绑定归属**使用 Halo 登录名和账号创建时间。修改显示名称不影响绑定。旧绑定在可确认归属时沿用，重新创建的同名 Halo 用户需要建立自己的绑定。换绑会核验网易云 UID 并切换加密凭据，解绑会使之前发起的确认失效。

## 偏好与缓存

- Folia 外观、播放、歌词等偏好即时生效。登录用户默认启用个人配置同步，已保存的开关优先。个人配置跟随当前 Halo 账号。
- 超级管理员改动可发布设置后，从设置窗口底部选择「保存为站点默认」。站点默认适用于游客和未覆盖相应字段的用户。可在「存储与备份 → Halo 配置同步」查看并恢复上一版站点默认。恢复后刷新音乐页。
- 在「存储与备份 → 缓存详情」开启、统计和清理歌曲缓存。智能过渡提示中的「开启歌曲缓存」指向同一个开关，开关可随个人偏好同步到 Halo。
- 歌词、封面、媒体、分析数据和播放会话留在当前浏览器。音频缓存复用前会核验曲目可用性。试听、私人曲目和需要会员权限的曲目继续在线取址。[配置同步快速接入](配置同步快速接入.md)

## 音乐 AI

在「工具设置 → 音乐 AI」启用功能，选择「所有已登录账号」或「仅指定角色」。首次安装时总开关默认开启。AI Foundation 需已启用，版本范围为 `>=1.4.0 <2.0.0`，并已配置默认语言模型。音乐页按实际可用性和账号权限显示对应入口。

| 能力 | 音乐页入口 |
| --- | --- |
| 歌词分词 | 「设置 → 歌词 → 分词」可开启自动处理。也可从快捷操作进入「歌词分词调整」。 |
| 歌曲配色 | 「设置 → 外观 → 歌曲主题」可选 AI 推断。也可在播放页「控制」面板对当前歌曲生成配色。 |

分词将待处理歌词行交给站点配置的模型。生成配色会发送歌名或最多 2,000 字歌词。生成结果保存在浏览器。旧音乐 AI 扩展设置可迁入主插件，主插件已保存的开关和角色优先。

## 网络与限流

### 代理

- **出站代理**用于插件连接网易云。代理地址和认证密钥都留空时直连。HTTP 或 SOCKS 代理的认证信息放在专用 Halo Secret，字段为 `username` 和 `password`。私网或带认证的代理需通过部署环境变量 `NCM_TRUSTED_OUTBOUND_PROXIES` 声明允许的 `主机:端口`，多项以逗号分隔。
- **可信反代**用于识别访问 Halo 的访客来源。默认只信任环回地址，使用内网反代时填写与 Halo 直接相连的代理 IP 或网段，按实际结构设置层数。
- 通用上传要求 Halo 写入权限和本人绑定，文件目标需通过网易云 HTTPS 地址校验。上传方式与字段见[开发与接口](开发与接口.md#http-接口)。

### 默认配额与缓存

| 项目 | 默认值 |
| --- | --- |
| 公开通用 API 和共用这个配额的音乐页读取 | 单 IP 每分钟 120 次，单进程公开读取共用每分钟 600 次。 |
| 通用个人接口及写入 | 每个 Halo 账号每分钟 120 次。个人曲库有独立计数。 |
| 音乐页搜索和联想 | 单 IP 每分钟分别为 20 次和 60 次。 |
| 播放取址 | 独立计数，游客按公开额度的两倍，登录后按个人额度的两倍。 |
| 后台接口调试 | 每个操作账号每分钟 30 次。 |
| 通用公开缓存、音乐页与主题查询缓存 | 默认分别为 300 秒、600 秒。 |
| 通用上传 | 单文件默认 100 MiB。 |

搜索、联想、歌词、探索、调试和账号操作有各自计数。公开与个人额度设为 `0` 时，对应的单 IP 或单账号额度关闭。公开共用上限及有独立预算的路由继续按各自规则工作。[音乐页路由](../src/main/java/cn/sky/ncm/page/MusicPageRouter.java) · [通用接口限流实现](../src/main/java/cn/sky/ncm/gateway/NcmGateway.java)

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| `/music` 无法访问 | 插件是否已启用，Halo 是否满足最低版本，以及「音乐首页 → 页面与分享」是否开启音乐页。 |
| 游客搜不到歌或一直取址失败 | 到「账号与游客」确认已注册，再看「维护」中的设备、公钥和代理。如果歌曲取址返回 `503`，待上游恢复后重试。 |
| 只能试听或提示不可播 | 取址以网易云实际返回为准。登录 Halo 并绑定自己的网易云账号后，可以用该账号的曲目权限重试。 |
| 看不到黑胶入口 | 确认已启用小播放器、音乐页开启及精选歌单仍可公开访问。 |
| 整页跳转后停在原进度 | 从小播放器点「继续播放」，浏览器允许时可自动恢复。局部导航和 Swup 接入的复验方法见[小播放器接入](站点小播放器接入.md#导航行为)。 |
| 找不到音乐 AI | 核对主插件开关、使用范围、AI Foundation 版本和默认语言模型。 |
| 升级后绑定不能读取 | 检查是否使用对应的 Halo 账号及原加密密钥。备份、迁移和回退见[构建与发布](构建与发布.md#升级与回退)。 |
